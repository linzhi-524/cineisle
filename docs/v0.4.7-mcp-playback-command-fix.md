# v0.4.7 MCP 远程播放修复

本版专门修复「AI / MCP 工具调用播放但手机端没有真正开始播放」的问题。

## 修复内容

- MCP 新增显式工具：`play_movie`、`pause_movie`、`seek_movie`，比原来的 `control_playback(paused:false)` 更不容易被模型误用。
- `control_playback` 现在不仅更新房间状态，还会写入一次 `context.playbackCommand` 远程播放命令。
- Android 端轮询房间时会优先识别 `context.playbackCommand`，按命令执行播放、暂停或跳转。
- 如果本机还没有导入/准备好影片，App 会显示「远程播放命令已收到，但本机还没导入/准备好影片」，不再像没有反应。
- 保留 v0.4.6 的聊天 token 兼容、截图状态提示、显式播放按钮修复。

- Server：`0.4.7-mcp-playback-command-fix`
