# v0.4.5 播放与聊天修复

本次修复两个用户反馈：

1. Android 端本地 MP4 播放几秒后自动暂停。
   - 原因：房间轮询会拉取远端旧的 `paused=true`，Android 端刚点播放还没来得及同步 `paused=false` 就被旧状态暂停。
   - 修复：增加本地播放动作时间戳、播放状态心跳、远端状态保护；本机刚播放/本机自己同步过的状态不会被旧远端暂停覆盖。

2. 聊天消息发出后过一会儿消失。
   - 原因之一：Android 端先本地乐观显示，若后端写入失败，下一次轮询会用远端空消息覆盖本地显示。
   - 原因之二：后端房间数据原本只在内存里，服务重启后 playback/context 请求可能重新创建空房间，导致消息列表被空房间覆盖。
   - 修复：Android 端保留本机待同步消息；后端新增 JSON 文件持久化，房间消息/笔记/卡片/播放状态变更会自动保存并在启动时恢复。

注意：Render 免费服务没有持久磁盘时，跨重新部署/重建容器仍可能丢文件。长期稳定建议接数据库或 Render Disk；本修复先解决运行中和普通重启后的明显丢消息问题。
