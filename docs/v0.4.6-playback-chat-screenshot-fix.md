# v0.4.6 播放 / 聊天 / 截图修复

- 新增显式「播放/暂停」按钮，点视频区域也会真正播放/暂停，不再只同步状态。
- 播放同步继续保留本机优先策略，避免旧远端暂停状态把本机播放拉停。
- 聊天发送时同时使用 Authorization、X-CineIsle-Token、body token 和 query token，提高不同后端/代理环境下的兼容性；失败时显示 HTTP 细节并保留本机待同步消息。
- 立即截图前检查后端地址和房间号；无障碍服务会把「未进入房间」「后端为空」「HTTP 失败详情」写到截图状态里，不再静默失败。
- 截图上传和远端截图请求也加了 query token / header 双保险。
